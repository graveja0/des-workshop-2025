Discrete Event Simulation for Health Economic Evaluation

Part 4. Building a DES Progressive Disease Model

Our next objective is to build in a single sick health state.

Notice that the sick state will allow for disease recovery (i.e., a return to the Healthy state).

We therefore need to add in two new transitions: (1) becoming ill; and (2) disease recovery.

Let’s now re-define the model inputs.

We include an annual hazard rate of progression from Healthy to Sick.

As well as an annual disease recovery rate.

The hazard rate of death from Healthy remains the same.

But patients in the sick state have a higher rate of death, as summarized by a hazard ratio.

Later we’ll build in some accounting of costs and quality of life, so we include cost and QALY parameters in the inputs as well.

Let’s add the sick state to the counters.

We must also be careful about how we initilize our patients.

In the example model, patients start off healthy. We’ll then define a numeric state variable–simmer requires this, and requires that 0 is the first value. So when state==0, the patient is in the healthy state.

The full model will also include a sicker health state, so we will assign a value of 1 for the sick state.

We’ll also want to track the amount of time spent in the healthy state later, for estimation of quality-of-life. So we need to add time in the healthy state to our resource counters.

Because the death rate now depends on health state, we amend our time_to_death function to draw a death time depending on whether the patient is Healthy or Sick.

inputs <- list(
    N       = 1,  # Total number of patients to simulate. 
    horizon = 110,  # Time horizon (years)
    min_age = 20,
    max_age = 30,
    r.HS1  =  0.15,   # Disease Onset Rate / year    (H  -> S)
    r.S1H  =  0.7,    # Recovery Rate / year         (S -> H)
    r.HD   =  0.005,  # Healthy to Dead rate / year  (H  -> D)
    hr.S1D =  3,      # Hazard ratio in S1 vs healthy 
    
    c.H    =  2000,      # Healthy individuals 
    c.S1   =  4000,      # Sick individuals in S1
    
    u.H    =     1.00,   # Healthy
    u.S1   =     0.80   # S1
)

# Define starting state of patient
initialize_patient <- function(traj, inputs)
{
  traj                   |>
  seize("time_in_model") |>
  set_attribute("AgeInitial", function() sample(20:30, 1)) |>
  set_attribute("State", 0) |> # Patients start healthy
  seize("healthy") 
}
years_till_death <- function(inputs)
{
  state <- get_attribute(env, "State")
  rate <- inputs$r.HD
  if(state == 1) rate <- rate * inputs$hr.S1D # Deal with Sick1 Hazard Ratio
  rexp(1, rate)
}
years_till_sick1 <- function(inputs)
{
  state <- get_attribute(env, "State") 
  if(state == 0) # 0 => Healthy
  {
    rexp(1,inputs$r.HS1)
  } else
  {
    inputs$horizon+1 # Past end of simulation time
  }
}
sick1 <- function(traj, inputs)
{
  traj                      |> 
  set_attribute("State", 1) |> # 1 => Sick 1 (S1)
  release('healthy')        |> # Track state change for tally later
  seize('sick1')
}
years_till_healthy <- function(inputs)
{
  state <- get_attribute(env, "State") 
  if(state == 1) # 1 => Sick 1
  {
    rexp(1,inputs$r.S1H)
  } else
  {
    inputs$horizon+1 # Past end of simulation time
  }
}

healthy <- function(traj, inputs)
{
  traj                      |> 
  set_attribute("State", 0) |> # 0 => Healthy (H)
  seize('healthy')          |>
  release('sick1')
}
cleanup_on_termination <- function(traj)
{
  traj |> 
  release("time_in_model") |>
  branch( 
    function() get_attribute(env, "State")+1,
      continue = rep(TRUE, 3),
      trajectory() |> release("healthy"),
      trajectory() |> release("sick1"),
      trajectory() 
  )
}
event_registry <- list(
  list(name          = "Terminate at time horizon",
       attr          = "aTerminate",
       time_to_event = function(inputs) inputs$horizon-now(env),
       func          = terminate_simulation,
       reactive      = FALSE),
  list(name          = "Death",
       attr          = "aDeath",
       time_to_event = years_till_death,
       func          = death,
       reactive      = TRUE),
  list(name          = "Sick1",
       attr          = "aSick1",
       time_to_event = years_till_sick1,
       func          = sick1,
       reactive      = TRUE),
  list(name          = "Healthy",
       attr          = "aHealthy",
       time_to_event = years_till_healthy,
       func          = healthy,
       reactive      = TRUE)
)
