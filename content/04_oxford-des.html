Discrete Event Simulation for Health Economic Evaluation

Part 4. Building a DES Progressive Disease Model

Our next objective is to build in a single sick health state.

Notice that the sick state will allow for disease recovery (i.e., a return to the Healthy state).

We therefore need to add in two new transitions: (1) becoming ill; and (2) disease recovery.

Let’s now re-define the model inputs.

We include an annual hazard rate of progression from Healthy to Sick.

As well as an annual disease recovery rate.

The hazard rate of death from Healthy remains the same.

But patients in the sick state have a higher rate of death, as summarized by a hazard ratio.

Later we’ll build in some accounting of costs and quality of life, so we include cost and QALY parameters in the inputs as well.

We’ll also cover point and interval discounting when we come to outcome estimation.

Let’s add the sick state to the counters.

Note that we index sick with a value of 1. That’s because simmer requires that health states be tracked using a numeric categorical variable that starts with zero.

We next add code initilise all patients into the healthy state.

We do this be setting the state attribute value to zero upon inilialisation of the patient.

We’ll also want to track the amount of time spent in the healthy state later, for estimation of quality-of-life. So we need to add time in the healthy state to our resource counters.

Because the death rate now depends on health state, we amend our time_to_death function to draw a death time depending on whether the patient is Healthy or Sick.

The function that draws years till sick uses a draw from the exponential distribution, and only sets a value within the simulation time horizon if the patient is in the healthy state.

Once the patient transitions into the sick state, we reset her state attribute to a value of 1 (i.e., sick).

She also releases the healthy resource and seizes the sick resouce. Again, this facilitates tracking total amount of time in each health state.

Recall that in this model, patients can recover and become healthy again.

To allow for this, we need to define a function for time to healthy and a function that releases the sick resource and re-seizes healthy.

We need to also amend our cleanup function so that it releases the healthy resource (if healthy) and sick resource (if sick) at the termination of the model.

Finally, we amend our event registry so that our model output records events for becoming ill and healthy.

Our des_run() function does not need to be amended because we took care of all the changes in the other model functions.

This table (from the res_model object) shows a partial trajectory for a single patient. We can see that the patient bounces back and forth between the healthy and sick health states.

With the simple Healthy-Sick-Dead model built, let’s now turn to outcome estimation.

Recall that earlier, we included cost and utility weights in the inputs.

Outcome estimation takes place after the model has run all patients. We do it by simply calculating and adding cost and QALY columns to the model output.

We’ll now define two functions, cost_arrivals() and qaly_arrivals() that take care of this process.

These functions will be tucked into the very end of the des_run() function we defined that runs the simulation model.

The function cost_arrivals() takes as its inputs the trajectory (“arrivals”) as well as the model inputs, which contains information on costs, utility weights, etc.

One nice feature of the DES trajectory is that it is easy to assign one-time costs.

For example, suppose there is a one-time cost of end-of-life care. We could simply add this at the time of death.

Let’s now discuss discounting in DES model outputs.

We have created a helper function discount_value() that takes care of continuous-time discounting for you.

Many approaches use the power definition of discounting, which in R utilises “^” operator. This limits the numerical stable range of the function.

Our function uses the exponential formulation with a greater numerical stability. The function also does point discounting or time period (i.e., integrated area) discounting.

For example, suppose we want to discount the value of 1, which occurs at precisely one year in the future. For example, this could be a one-time treatment cost.

Now suppose we want to discount the value 1 over the time period \(t=0\) to \(t=1\). For example, this type of discounting would apply for time spent in a health state.

Our cost calculation approach applies the discount_value() function to all time periods to calculate discounted costs.

We define a similar qaly_arrivals() function to calculate quality of life based on utility weights.

The only major difference is that we multiply time in each health state with its corresponding utility weight.

inputs <- list(
    N       = 1,  # Total number of patients to simulate. 
    horizon = 110,  # Time horizon (years)
    min_age = 20,
    max_age = 30,
    r.HS1  =  0.15,   # Disease Onset Rate / year    (H  -> S)
    r.S1H  =  0.7,    # Recovery Rate / year         (S -> H)
    r.HD   =  0.005,  # Healthy to Dead rate / year  (H  -> D)
    hr.S1D =  3,      # Hazard ratio in S1 vs healthy 
    
    c.H    =  2000,      # Healthy individuals 
    c.S1   =  4000,      # Sick individuals in S1
    
    u.H    =     1.00,   # Healthy
    u.S1   =     0.80,   # S1
    
    # Cycle => 1 year
    d.r    =     0.03   # Discount Rate
)
counters <- c(
  "time_in_model",
  "death",
  "healthy",
  "sick1"
)
  
# Define starting state of patient
initialize_patient <- function(traj, inputs)
{
  traj                   |>
  seize("time_in_model") |>
  set_attribute("AgeInitial", function() sample(20:30, 1)) |>
  set_attribute("State", 0) |> # Patients start healthy
  seize("healthy") 
}
years_till_death <- function(inputs)
{
  state <- get_attribute(env, "State")
  rate <- inputs$r.HD
  if(state == 1) rate <- rate * inputs$hr.S1D # Deal with Sick1 Hazard Ratio
  rexp(1, rate)
}
years_till_sick1 <- function(inputs)
{
  state <- get_attribute(env, "State") 
  if(state == 0) # 0 => Healthy
  {
    rexp(1,inputs$r.HS1)
  } else
  {
    inputs$horizon+1 # Past end of simulation time
  }
}
sick1 <- function(traj, inputs)
{
  traj                      |> 
  set_attribute("State", 1) |> # 1 => Sick 1 (S1)
  release('healthy')        |> # Track state change for tally later
  seize('sick1')
}
years_till_healthy <- function(inputs)
{
  state <- get_attribute(env, "State") 
  if(state == 1) # 1 => Sick 1
  {
    rexp(1,inputs$r.S1H)
  } else
  {
    inputs$horizon+1 # Past end of simulation time
  }
}

healthy <- function(traj, inputs)
{
  traj                      |> 
  set_attribute("State", 0) |> # 0 => Healthy (H)
  seize('healthy')          |>
  release('sick1')
}
cleanup_on_termination <- function(traj)
{
  traj |> 
  release("time_in_model") |>
  branch( 
    function() get_attribute(env, "State")+1,
      continue = rep(TRUE, 3),
      trajectory() |> release("healthy"),
      trajectory() |> release("sick1"),
      trajectory() 
  )
}
event_registry <- list(
  list(name          = "Terminate at time horizon",
       attr          = "aTerminate",
       time_to_event = function(inputs) inputs$horizon-now(env),
       func          = terminate_simulation,
       reactive      = FALSE),
  list(name          = "Death",
       attr          = "aDeath",
       time_to_event = years_till_death,
       func          = death,
       reactive      = TRUE),
  list(name          = "Sick1",
       attr          = "aSick1",
       time_to_event = years_till_sick1,
       func          = sick1,
       reactive      = TRUE),
  list(name          = "Healthy",
       attr          = "aHealthy",
       time_to_event = years_till_healthy,
       func          = healthy,
       reactive      = TRUE)
)
des_run <- function(inputs)
{
  env  <<- simmer("SickSicker")
  traj <- des(env, inputs)
  env |> 
    create_counters(counters) |>
    add_generator("patient", traj, at(rep(0, inputs$N)), mon=2) |>
    run(inputs$horizon+1/365) |> # Simulate just past horizon (in years)
    wrap()
        
  get_mon_arrivals(env, per_resource = T) 
}

des_run <- function(inputs)
{
  env  <<- simmer("SickSicker")
  traj <- des(env, inputs)
  env |> 
    create_counters(counters) |>
    add_generator("patient", traj, at(rep(0, inputs$N)), mon=2) |>
    run(inputs$horizon+1/365) |> # Simulate just past horizon (in years)
    wrap()
        
  get_mon_arrivals(env, per_resource = T) |>
    cost_arrivals(inputs) |> 
    qaly_arrivals(inputs) 
}
cost_arrivals <- function(arrivals, inputs)
{
  arrivals$cost  <- 0  # Undiscounted costs are 0 to begin
  arrivals$dcost <- 0  # Discounted costs are 0 to begin
  
  selector = arrivals$resource == 'healthy'
  arrivals$cost[selector] <- inputs$c.H *
    (arrivals$end_time[selector] - arrivals$start_time[selector])
  arrivals$dcost[selector] <- discount_value(inputs$c.H,
    arrivals$start_time[selector], arrivals$end_time[selector],
    annual_rate = inputs$d.r)
  
  selector = arrivals$resource == 'sick1'
  arrivals$cost[selector] <- inputs$c.S1 *
    (arrivals$end_time[selector] - arrivals$start_time[selector])
  arrivals$dcost[selector] <- discount_value(inputs$c.S1,
    arrivals$start_time[selector], arrivals$end_time[selector],
    annual_rate = inputs$d.r)
 
  arrivals
}

discount_value <- function(value, t_A, t_B=NULL, annual_rate=0.03, scale=1)
{
  # Scale to time step
  if(scale != 1)
  {
    t_A <- t_A / scale
    if(!is.null(t_B)) t_B <- t_B / scale
  }
  
  # Convert discount to continuous exponential rate
  r <- -log(1+annual_rate) 

  if(is.null(t_B))
  { # Point estimate at t_B
    value*exp(r*t_A)
  } else 
  { # Analytic integral of curve
    (value/r)*(exp(r*t_B)-exp(r*t_A))
  }
}

qaly_arrivals <- function(arrivals, inputs)
{
  arrivals$qaly  <- 0  # No qaly yet
  arrivals$dqaly <- 0  # No discounted qaly either
  
  selector <- arrivals$resource == 'healthy'
  arrivals$qaly[selector] <-
    inputs$u.H*
     (arrivals$end_time[selector] - arrivals$start_time[selector])
  arrivals$dqaly[selector] <- 
      discount_value(inputs$u.H, 
                     arrivals$start_time[selector],
                     arrivals$end_time[selector],annual_rate = inputs$d.r)
  
  selector <- arrivals$resource == 'sick1'
  arrivals$qaly[selector] <-
    inputs$u.S1*
     (arrivals$end_time[selector] - arrivals$start_time[selector])
  arrivals$dqaly[selector] <- 
      discount_value(inputs$u.S1, 
                     arrivals$start_time[selector],
                     arrivals$end_time[selector],annual_rate = inputs$d.r)
  
  arrivals
}
